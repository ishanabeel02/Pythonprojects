# Python Projects

## Code Smell Detection in AI-Generated Python Projects

This repository contains a collection of Python projects generated using multiple AI coding assistants — including **ChatGPT (GPT-5)**, **GitHub Copilot**, and **DeepSeek-V3**. These projects were created and analyzed as part of a research study on **code smells** in AI-generated software.

Each project consists of **77–534 lines of code** and represents small to medium-sized applications such as management systems, calculators, and simple games. The repository aims to evaluate and compare the **code quality**, **maintainability**, and **structural characteristics** of AI-generated code using established code analysis tools.
